# Security policy

Report security problems privately through GitHub's private vulnerability
reporting: open the repository's
[Security tab](https://github.com/vycdev/isometric-contributions-plus/security)
and choose **Report a vulnerability**, or go straight to the
[report form](https://github.com/vycdev/isometric-contributions-plus/security/advisories/new).
Please don't open a public issue for a security problem.

If you can't use GitHub, email vycdev@gmail.com instead.

Fixes ship in the latest version only.
