# Privacy Policy

Isometric Contributions Plus is a browser extension that renders GitHub contribution graphs as isometric 3D pixel art.

## Data Collection

This extension does not collect, store, or transmit any personal data. It does not use analytics, tracking, or any third-party services.

## Data Usage

The extension reads contribution data from the GitHub profile page you are viewing and may request earlier contribution years from GitHub to calculate streaks. Rendering and statistics are processed within your browser; the extension does not send this data to a separate service.

## Storage

The extension stores your view preference (2D, 3D, or Both) and height scale locally in your browser using the browser's built-in storage API. These settings never leave your device.

## Contact

If you have questions about this privacy policy, you can open an issue at https://github.com/vycdev/isometric-contributions-plus/issues. Issues are public; do not include private information. A private reporting contact has not been configured for this fork; see [publishing and contact setup](PUBLISHING.md#support-and-private-reporting).
